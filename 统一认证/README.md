## 关键决策摘要（2026-08-20）

1. 短信通道复用公司现有通道；
2. 各端小程序为独立 AppID，已绑定同一微信开放平台账号（unionid 归并可用）；
3. 管理控制台挂入统一管理后台，作为「账号管理」模块（非业务管理后台）；
4. 认证中心只返回状态码（guide_status），业务页面归各业务端；
5. 原规划一期、二期合并实施为现「一期」，数据范围正式建模，不走临时过渡；
6. 端清单 8 个（含自研 SCRM 待建、客户端/月嫂端双 APP）；月嫂招聘小程序开放注册，用户统一建模为第五类主体 promoter（自荐/推荐均生成线索）。
