# 渠道推广系统 — 产品架构与需求文档


---

## 一、背景与目标

### 1.1 业务背景
护理招募培训系统目前仅支持内部运营人员管理渠道和记录数据。随着业务扩张，需要引入**外部推广力量**（地推人员、在岗阿姨、合作伙伴、自媒体等），通过利益驱动让更多人帮助公司招募护理人员。

### 1.2 设计目标
- **降低推广门槛**：外部人员无需进后台，手机端即可完成推广全流程
- **利益透明可见**：推广人随时可查自己的推广数据和预计收益
- **归属准确可追溯**：被推荐人从点击链接到最终上户，全链路归因清晰
- **结算自动化**：减少人工对账和打款操作，降低运营成本
- **防作弊与风控**：防止刷单、重复结算等恶意行为

## 二、用户角色定义

| 角色 | 定义 | 使用端 | 核心诉求 |
|------|------|--------|----------|
| **系统管理员** | 公司高层/产品负责人 | 后台 | 全局数据看板、渠道投入产出比、风险控制 |
| **渠道运营** | 负责渠道拓展和推广的运营人员 | 后台 | 管理渠道、推广人、配置佣金规则、处理结算 |
| **财务人员** | 负责佣金打款和结算 | 后台 | 佣金打款确认、对账 |
| **一级分销商** | 渠道开发人员、培训机构、公司员工 | 后台 | 发展二级分销商、查看团队业绩、获得团队分成 |
| **二级分销商（推广人）** | 月嫂、在岗阿姨、地推人员等 | 小程序 | 获取推广物料、推荐月嫂报名、查看业绩、申请提现 |
| **被推荐人** | 月嫂/护理人员，最终提供服务的人 | 小程序 | 了解岗位、选择岗位、报名、接受派单 |

## 四、功能模块全景图

### 4.1 后台管理系统（5大模块）

#### 模块 A：渠道管理（增强现有 channel.html）
| 功能点 | 详细说明 |
|--------|----------|
| 渠道 CRUD | 新增/编辑/停用/删除渠道，支持线上/线下/转介绍/合作伙伴 |
| 渠道状态管理 | 启用中/已停用，停用后该渠道下推广链接失效 |
| 渠道推广物料 | 自动生成渠道专属二维码和推广链接，支持下载 |


#### 模块 B：推广人管理
| 功能点 | 详细说明 |
|--------|----------|
| 推广人列表 | 查看所有推广人，支持按渠道/状态/业绩筛选 |
| 推广人详情 | 个人信息、推广数据、佣金明细、提现记录、操作日志 |
| 推广人状态管理 | 正常/冻结，冻结后停止结算新佣金 |
| 推广人分级 | 1~5星推广人，基于上月佣金自动评定，每月1号重置到1星 |


#### 模块 C：佣金规则配置
| 功能点 | 详细说明 |
|--------|----------|
| 全局规则 | 基础提成比例、奖励次数上限、绑定有效期、等级加成开关 |
| 渠道级规则 | 针对特定渠道覆盖全局规则，手动开关控制是否生效 |
| 推广人等级规则 | 1~5星推广人，基于上月佣金自动评定，每月1号重置到1星 |


#### 模块 D：结算管理
| 功能点 | 详细说明 |
|--------|----------|
| 打款列表 | 查看所有提现申请，支持按状态筛选（待打款/已打款/打款失败） |
| 批量打款 | 一键全部打款 |
| 打款详情 | 查看每笔申请的银行卡信息、佣金来源明细 |
| 异常处理 | 打款失败展示失败原因，支持拒绝操作 |

#### 模块 E：全局参数配置
| 功能点 | 详细说明 |
|--------|----------|
| 佣金计算方式 | ~~固定金额 /~~ 比例提成（仅比例提成） |
| 佣金比例 | 合同金额 × 比例 = 奖励金额（默认 0.5%，范围 0.1%~5%） |
| 奖励次数上限 | 同一被推荐人最多产生奖励次数（默认 5 次，范围 2~10） |
| 结算节点 | 已下户后结算（固定，不可配置） |
| 绑定有效期 | 无上户自动解绑期限（默认 6 个月，范围 3~12） |
| 二级分销开关 | 开启/关闭二级分销 |
| 一级分成比例 | 一级推广人分成比例（默认 80%） |
| 二级分成比例 | 二级推广人分成比例（默认 20%） |
| 一级+二级 | 必须等于 100%，无平台保留 |

### 4.2 推广人 小程序端（5个页面）

#### 页面 1：注册成为推广人
- 手机号注册（验证码校验）
- 协议勾选确认（《推广人协议》+《服务条款》，默认未勾选，必须勾选后才能注册）

#### 页面 2：推广中心首页
- 快捷推广入口（分享海报、查看奖励规则）
- 本月推荐排行（名字脱敏处理）
- 奖励规则弹窗（含等级加成说明）
- 推广海报弹窗
- 未登录引导

#### 页面 3：接单赚钱
- 月份筛选（支持滑动选择上单时间）
- 订单卡片（服务类型、到手服务费、预产期、服务地址、胎次、服务要求）
- 滚动通知栏（展示最新预订动态）
- 立即抢单 / 分享给姐妹

#### 页面 4：佣金钱包
- 余额头部（可提现余额、待结算金额）
- 统计卡片（待结算、累计收入）
- 佣金明细 / 提现记录标签页
- 提现申请弹窗（仅支持银行卡，需配置真实姓名、身份证号、开户银行、银行卡号）
- 银行卡信息配置弹窗（未配置时提现前强制填写）
- 佣金规则说明弹窗（含等级加成预览）

#### 页面 5：个人中心
- 个人信息头部（头像、昵称、推广人ID、等级标签）
- 推广等级进度条（距下一等级所需佣金）
- 统计条（累计报名 / 累计签约 / 累计上户 / 累计下户）
- 直接推荐 / 团队推荐列表（含推荐时间、按时间新→旧排序、搜索+状态筛选）
- 我的钱包入口
- 底部导航（接单赚钱 / 推荐赚钱 / 我的）

### 4.3 被推荐人报名端
- 渠道参数自动识别（小程序 `scene` 参数或 `path` 中的 referrer）
- 小程序 Storage 追踪（`wx.setStorageSync` 持久保存推广人 referrer）
- 服务端 openId 映射（同一微信用户长期绑定同一推广人）
- 基本信息填写（姓名、手机、年龄、目标岗位、经验、期望薪资、备注）
- "谁推荐你来的？"字段（下拉选择推荐人，非必填）
- 如果通过推广链接/小程序码访问，自动填充推荐人信息并不可修改

## 五、核心规则定义

### 5.1 推广归因规则

| 规则项 | 定义 |
|--------|------|
| **绑定建立** | A（被推荐人）通过 B 的推广链接/小程序码完成报名 → A 绑定到 B 名下 |
| **归因优先级** | ① 小程序 Storage referrer（最高）> ② openId 映射表 > ③ 手动填写 |
| **归属冲突处理** | 同一被推荐人存在多个推广来源时，以**首次有效绑定**为准（First-Touch），绑定后不可切换 |
| **绑定有效期** | A 绑定后 **6 个月**内无上户记录，自动解绑（可配置范围 3~12 个月） |
| **自然流量归属** | 无推广来源的报名归为"自然流量"，不计入任何推广人业绩 |
| **跨设备处理** | 同一微信账号 openId 一致，服务端映射表保证归因连续；更换微信账号视为新用户 |

### 5.2 佣金计算规则

#### 计算方式

仅支持**比例提成**模式，固定金额模式已移除。

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **比例提成** | 单次上户奖励 = 该次服务合同金额 × 配置比例 | 月嫂上户后按合同金额提成 |

#### 比例提成配置项

| 配置项 | 默认值 | 可配置范围 |
|--------|--------|------------|
| 佣金比例 | 0.5% | 0.1% ~ 5% |
| 奖励次数上限 | 5 次 | 2 ~ 10 次 |
| 结算节点 | 已下户后结算 | 固定，不可配置 |

**示例**：A 月嫂某次上户合同金额 15,000 元，比例 0.5%，B 获得奖励 = 15,000 × 0.5% = 75 元

#### 二级分销佣金分配

| 层级 | 角色 | 分成比例（可配置） |
|------|------|-------------------|
| 一级 | 渠道/员工/培训机构 | 80%（默认） |
| 二级 | 月嫂/阿姨（直接推荐人） | 20%（默认） |

**规则**：一级 + 二级 = 100%，无平台保留

**示例**：合同金额 15,000 元，总佣金 75 元 → 一级拿 60 元，二级拿 15 元


#### 转介绍特殊规则（在岗阿姨）
- 被推荐人可获得 **培训费减免 200 元**（双向奖励）

### 5.3 结算规则

| 规则项 | 定义 |
|--------|------|
| **结算节点** | 已下户后结算（服务周期结束、客户确认后），固定不可配置 |
| **结算周期** | 推广人可申请提现的时间：每月 1-5 日、15-20 日 |
| **最低提现额** | 50 元 |
| **到账方式** | 银行卡（1-3 工作日） |
| **税费处理** | 单月佣金超过 800 元部分，按劳务报酬代扣代缴个人所得税 |
| **退款冲抵** | 被推荐人退课/离职/服务未完成，已结算佣金从后续余额中扣除 |
| **奖励次数限制** | 同一被推荐人达到奖励次数上限后，后续上户不再产生现金奖励 |

### 5.4 推广人星级体系

| 星级 | 名称 | 升级条件（上月佣金） | 佣金加成 | 专属权益 |
|------|------|---------------------|----------|----------|
| 1星 | 1星推广人 | 无（默认） | 0% | 基础佣金比例 |
| 2星 | 2星推广人 | ≥ 500 元 | +5% | 佣金加成5% |
| 3星 | 3星推广人 | ≥ 1,500 元 | +8% | 佣金加成8% |
| 4星 | 4星推广人 | ≥ 5,000 元 | +10% | 佣金加成10% + 优先派单 |
| 5星 | 5星推广人 | ≥ 15,000 元 | +15% | 佣金加成15% + 专属客服 |

**等级规则**：
1. 每月1号凌晨系统自动将所有推广人等级重置为「1星推广人」
2. 系统根据推广人上月累计佣金金额，自动匹配对应等级
3. 等级越高，佣金加成比例越高，享受的权益越多

## 七、关键数据指标（北极星指标）

| 指标类型 | 指标名称 | 计算方式 |
|----------|----------|----------|
| **核心指标** | 推广渠道签约占比 | 推广渠道带来的签约人数 / 总签约人数 |
| **核心指标** | 推广人活跃率 | 本月有推广行为的推广人 / 总推广人数 |
| **效率指标** | 单推广人月均签约 | 推广渠道总签约数 / 活跃推广人数 |
| **效率指标** | 推广获客成本 | 推广佣金总支出 / 推广渠道签约人数 |
| **效率指标** | 线索→签约转化率 | 推广渠道签约人数 / 推广渠道线索数 |
| **效率指标** | 绑定有效期内上户率 | 绑定后 6 个月内完成首次上户的人数 / 总绑定人数 |
| **健康指标** | 推广人留存率 | 本月活跃且上月也活跃的推广人 / 上月活跃推广人 |
| **健康指标** | 提现完成率 | 成功打款的提现申请 / 总提现申请 |
| **健康指标** | 二级分销商发展数 | 一级分销商发展的有效二级数量 |
| **监控指标** | 异常线索占比 | 被判定为异常的线索 / 总线索数 |
| **监控指标** | 绑定过期解绑率 | 到期自动解绑人数 / 总绑定人数 |

## 八、边界场景与异常处理

| 场景 | 处理方案 |
|------|----------|
| 推广链接被转发到多个群，多人点击 | 以**首次有效绑定**为准，绑定后不可切换 |
| 被推荐人已绑定在 B 名下，C 向 A 发链接试图重新绑定 | 系统提示 A "您已被 B 推荐"，保持 B 的归属；过期解绑后才可重新绑定 |
| 被推荐人报名后长期无进展（6个月无上户） | 系统标记为"沉睡用户"，通知推荐人跟进；超过绑定有效期自动解绑 |
| 被推荐人已绑定，但超过奖励次数上限后再次上户 | 不再产生现金奖励 |
| 被推荐人上户后客户中途退单/换人 | 若退单发生在已下户前：该次不计入奖励次数；若已结算现金需追回 |
| 被推荐人退课/离职 | 已结算佣金从推广人余额扣除；余额不足记为负账 |
| 推广人银行卡信息错误导致打款失败 | 通知推广人更新银行卡，3 次失败后冻结提现功能 |
| 推广人被冻结 | 已产生的待结算佣金正常结算，冻结后不再产生新佣金 |
| 同一手机号为多个推广人的被推荐人 | 系统去重，只算 1 条线索；如果多个推广人都 claim，以首次有效归属为准 |
| 推广人申诉佣金少算 | 提交申诉 → 运营核查归因记录和状态流转 → 3 个工作日内回复 |
| 佣金规则中途变更 | 已产生的按旧规则结算，新产生的按新规则；规则变更需提前 7 天通知推广人 |
