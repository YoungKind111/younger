# 订单变更优化 · 文档中心

月子服务业务「订单变更」改版项目的产品文档站，覆盖 **申请 → 审核 → 退款联动 → 结果反馈** 完整链路。

## 本次改版四件事

1. **统一申请入口**：顾问/前台端统一申请表单，套餐变更、发起退款、客户声音三类事项自由组合；
2. **统一审核视图**：后台审核界面完整展示订单信息、变更详情、关联退款明细与汇总、审核记录；
3. **建立联动规则**：订单变更通过则关联退款全部通过，订单变更驳回则关联退款全部驳回；
4. **强化规则提示**：审核弹窗等关键操作位置显著提示联动规则，避免误操作。
